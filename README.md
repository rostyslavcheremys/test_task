# Структура проєкту

```
index.html           — головна сторінка
thanks.html          — сторінка подяки (thx)

css/
  reset.css          — обнулення стилів браузера
  bootstrap-grid.min.css — бібліотека сітки
  fonts.css          — підключення шрифтів
  style.css          — основні стилі
  adaptive.css       — адаптивні стилі
  popup_style.css    — стилі спливаючого вікна
  thx.css            — стилі сторінки подяки
  nunito-fonts.css   — @font-face для шрифту Nunito
  phone-input.css    — стилі поля вводу телефону
  form-loader.css    — оверлей і спінер завантаження форми заявки
  form-animations.css — @keyframes для анімацій форми заявки
  reg-form.css       — стилі блоку форми заявки
  topblock.css       — стилі верхнього блоку

js/
  timer.js           — таймер

fonts/
  montserrat/        — шрифт Montserrat
  ttfirsneue/        — шрифт TT Firs Neue

images/
  icons/             — дрібні іконки, лого, стрілки, зірки тощо
  exchanges/         — логотипи бірж
  comments/          — фото у відгуках/коментарях
  celebs/            — фото знаменитостей (фонові блоки)
  screenshots/       — скріншоти інтерфейсу
  decor/             — декоративна графіка
  thanks/            — зображення для сторінки подяки
